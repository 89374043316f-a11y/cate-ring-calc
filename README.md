# Калькулятор кейтеринга

Многостраничный калькулятор кейтеринга для планирования мероприятий: расчёт количества продуктов, напитков, алкоголя, шашлыка, цен и КБЖУ.

## Структура проекта

```
.
├── index.html          # Главная страница (HTML-разметка)
├── css/
│   └── style.css       # Все стили
├── js/
│   ├── app.js          # Основная логика (калькулятор, цены, КБЖУ, продукты)
│   └── inline-edit.js  # Скрипт инлайн-редактирования
└── README.md
```

## Деплой на Cloudflare Pages

1. Загрузите файлы в GitHub-репозиторий (Public или Private)
2. В Cloudflare Dashboard: Pages → Create a project → Connect to Git
3. Выберите репозиторий
4. Настройки сборки:
   - **Build command:** (оставьте пустым)
   - **Build output directory:** `/` (корень)
5. Нажмите Save and Deploy

Сайт полностью статический — не требует серверной части.
